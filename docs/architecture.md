## 一句话架构

UI 只调应用层，应用层只认 Provider 接口，驱动只管一家云的协议，
同步引擎只认统一的 Node 模型。任何一层换实现，其他层都不用改。

## 同步任务界面（2026-11-24 补充，晚间定版）

按 Air Explorer 式双栏：左右各一个文件管理器（左源、右目标），更易懂。
实现见 `frontend/src/pages/SyncJobs.tsx`。

**2026-11-24 21:39 最终选型：方案 A（全屏双栏）定版**，四方案
（A 全屏双栏 / B FreeFileSync 对比表 / C 任务卡+右侧配置 /
D MultCloud 向导）中选 A，其余方案已从 demo 下线：

- 进同步页先展示「已保存的任务」列表；点「创建同步任务」才弹出
  双栏对比框；创建成功后自动回到列表并定位到新任务卡。
- 左侧导航栏常驻（同步页只收右侧检查器，不收左栏）。
- 任务可命名：双栏顶部有任务名称输入框，空名字不让创建。
- 过滤规则：排除规则，一行一个，留空 = 全部同步；对比预览里被
  排除的文件标「已排除」，不计入新增/覆盖。
- 双栏交互（2026-11-24 22:04）：同步页点左侧网盘跳转到文件浏览；
  点任务的「在双栏中打开」，双栏在该任务卡下方像手风琴一样展开，
  而不是在顶部打开。
- 对比自动、递归、应用过滤：改路径/方向/方式/过滤后防抖重算，
  不再清空；选中文件夹就是同步根；编辑任务按完整路径回填；
  镜像删除数>0 时创建按钮旁常驻提示，不用连点两次。
- 「创建任务并同步」真的开始跑（进右下角传输浮条），创建后滚动
  定位到新任务卡并高亮。

## UI 原则（2026-11-24 补充）

后端逻辑借鉴 Pail，UI 层重写（Pail 只支持单个 S3，产品是多网盘）；
专业项留着、可以不用、不能没有——默认收进高级/详情里，按 Provider
能力表有无显示。实现见 `frontend/src/components/Inspector.tsx`。

**2026-11-24 晚间定版的其余 UI 决策**（均已在 UI demo 定版，
`internal/app` 与 `frontend/` 按此实现，见下）：

- 文件浏览右侧详情按需展示：默认不显示，表格占满；只有点击文件/
  文件夹后才展示，点空白/已选行/关闭可收起；双击进目录不弹详情。
- 网盘分组：左栏挂载按分组展示（默认工作/个人/存储·备份），分组
  可折叠/展开、新建/重命名/删除；分组数量挨着分组名称显示，不放
  右侧；编辑与删除按钮默认不展示，鼠标悬停时才展示编辑；删除需
  二次确认，组内有网盘时提示并选择迁移到未分组、其他分组或新建
  分组；删组不删盘。模型：`Mount.Group`（"" = 未分组）。
- 传输队列/最近同步记录：不一直占底栏，收进右下角浮条；默认只
  显示图标+进行中数量，无任务时只剩小按钮；有任务或点击才展开
  面板（传输队列/最近同步两个标签）。
- 多 Agent：设置里的 Agent 是列表（名字/地址/在线状态/版本/协议
  版本/在跑任务数/上次心跳），支持添加（名字+地址+Token）、编辑、
  删除、测试连接、设为默认；同步任务的执行位置可选本机或某一台
  具体 Agent（离线置灰）。模型：`domain.Agent` + `cache.agents`
  表 + `App.agents`。
- 本地文件夹同步：同步任务的源/目标可选手册本地文件夹
  （`local://<绝对路径>`，`domain.LocalMountID`）；本地端只能在
  本机执行，选 Agent 时提示并置灰，`ValidateJob` 强制拦截；
  本地到本地也可建任务。驱动：`internal/storage/providers/local`。
- 多账号隔离：按 Mount 隔离，不是按类型——一个类型可挂多个账号
  （如 OneDrive1/OneDrive2），Token/缓存/游标/同步任务各走各的。
  实现：`App.AddMount` 按 mount_id 建实例，驱动实例不共享状态；
  注册表只存工厂，不存实例。

## 分层

```
cmd/desktop · cmd/agent · cmd/cli   入口层：只组装
frontend/                           界面层：只展示与收集输入
internal/app                        应用层：账号/浏览/传输/任务
internal/sync · transfer · cache    引擎层
internal/storage                    存储接口：Provider + 能力表 + 注册表
internal/storage/providers/*        驱动层：一家云一个目录
internal/platform · auth            公共层：HTTP/分片/调度/OAuth（无业务状态）
```

## 六条约束

1. 界面不直连驱动；2. 上层不认厂商；3. 删除必预览；
4. 状态必落盘；5. 密钥必加密；6. 版本必协商。
